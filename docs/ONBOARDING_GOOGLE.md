# Onboarding Google (GSC + GA4 + Ads)

Objetivo: conectar credenciales y validar accesos por proyecto.

Checklist:
- GSC: property verificada y accesible por la cuenta/SA configurada
- GA4: property ID correcto y permisos de lectura
- Ads: `ads_customer_id` válido y permisos suficientes (gate del producto)

Definición de “OK”:
- Cada botón “Test access” debe ejecutar un request mínimo, guardar raw response y marcar estado OK/FAIL.
